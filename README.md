This is a console-based application written in C++ designed to demonstrate all the core principles of Object-Oriented Programming (OOP). It is a great learning project for beginners to see how each OOP concept is implemented and used in a real-world scenario.

🔍 Key OOP Concepts Demonstrated
✅ 1. Class and Object
The foundation of OOP.

The application uses multiple classes, and objects are created to interact with those classes.

✅ 2. Encapsulation
Data members are kept private or protected, and access is provided through public member functions (getters/setters).

Keeps internal class details hidden and secure.

✅ 3. Abstraction
Complex logic is hidden behind simple interfaces.

Only essential information is exposed to the user through method calls.

✅ 4. Inheritance
Classes reuse properties and behaviors from parent classes.

Demonstrates single and possibly multilevel inheritance depending on your app.

✅ 5. Polymorphism
Supports compile-time polymorphism using function overloading.

Supports run-time polymorphism using virtual functions and function overriding.

✅ 6. Constructor and Destructor
Each class has its own constructor(s) and destructor to manage object lifecycle and resource cleanup.

✅ 7. Access Specifiers
Use of public, private, and protected keywords to control visibility and access level of members.

✅ 8. File Handling 
Although not part of core OOP, file handling is integrated to store and retrieve data, showing practical usage with OOP classes.
